# 공용 장부 연결 안내 (사장님용)

개통장부 앱의 기록을 **구글 시트 한 곳에 모으고, 직원 폰과 실시간으로 맞추는** 설정입니다.
**한 번만** 하면 되고, 걸리는 시간은 3~5분입니다.

- 시트: **충주 KT대리점 칠금점 개통장부**
  https://docs.google.com/spreadsheets/d/1DjKKQT9K2ryDKjRL88B31pMhdqgqlzEX39uDbG8F4E4/edit
- 시트 구조: `전체_통합`(모든 기록) + `담당_김태양` `담당_김설화` `담당_이건엽` `담당_권영한` `담당_전국현`(자동 분류 보기)
  + 숨김 탭 `_접속기기`(앱을 연 기기 기록) `_차단`(추방한 기기·직원) — 앱이 만드는 탭이라 지우거나 고치지 마세요
- 매장 접속 PIN: **5001** (조회·등록·수정)
- 관리자 PIN: **0525** (삭제·엑셀·백업·**직원·기기 추방** — 앱의 관리자 모드)

> **앱 v10부터 추가된 항목도 재배포가 필요 없습니다.** `단말보험`(미가입·가입)과
> 요금제 변경 / 부가서비스 해지 **완료 표시**는 시트의 `메모` 칸에 `[단말보험]` `[요금완료]` `[부가완료]`
> 표기로 함께 저장됩니다. 그래서 `Code.gs`는 지금 배포된 그대로 두면 되고, 앱에서는 그 표기가 메모에 보이지 않습니다.

## 1단계 — 시트에 스크립트 붙이기

1. 위 시트를 엽니다. (사장님 계정 `kbs2106@nate.com`으로 로그인된 상태)
2. 위쪽 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 새 창에 코드가 조금 적혀 있으면 **전부 지웁니다** (Ctrl+A → Delete).
4. 이 폴더의 **`Code.gs` 파일 내용 전체**를 복사해 붙여넣습니다.
5. 위쪽 **💾 저장**(또는 Ctrl+S) → 프로젝트 이름은 `개통장부 연동` 정도로.

> 폰에서는 시트 앱 → 우측 상단 ⋮ → "부가기능" 메뉴가 없어 확장 프로그램을 열 수 없습니다.
> **이 1단계만 PC(또는 태블릿 데스크톱 모드)에서** 하시고, 나머지는 폰에서도 됩니다.

## 2단계 — 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 왼쪽 톱니바퀴(유형 선택) → **웹앱**.
3. 아래처럼 설정합니다.
   - 설명: `개통장부 공용 저장소`
   - **실행 대상: 나**
   - **액세스 권한: 모든 사용자** ← 이게 아니면 직원 폰에서 로그인 화면이 떠서 연결이 안 됩니다
4. **배포** → 구글 계정 권한 요청이 나오면
   `권한 검토 → 계정 선택 → 고급 → (안전하지 않음) 이동 → 허용`.
5. 나오는 **웹앱 URL**(`https://script.google.com/macros/s/AKfy…/exec`)을 복사합니다.

## 3단계 — 앱에 주소 넣기 (사장님 폰/PC)

1. 개통장부 앱을 엽니다. (https://kbs2106-oss.github.io/kt-store-manager/)
2. **더보기 → 공용 장부 연동 (Google 시트)**.
3. **연동 주소**에 복사한 `/exec` 주소를 붙여넣고, **매장 PIN** `5001`, **내 이름** `김태양` 선택.
4. **연결 테스트** → “연결 성공! 시트에 N건이 있습니다.” 가 나오면 **저장**.
5. 상단에 `공용 장부 · 방금 동기화` 배지가 뜨면 성공입니다.

## 4단계 — 직원 폰 연결

직원은 같은 앱 주소를 열고 **더보기 → 공용 장부 연동**에서
**연동 주소 + PIN 5001 + 자기 이름**(김설화 / 이건엽 / 권영한 / 전국현)만 넣고 저장하면 됩니다.
이후 서로 등록한 개통이 **각자 폰에 자동으로** 나타납니다.

> 앱 상단의 `index.html` 안 `DEFAULT_SYNC` 에 배포 주소를 넣어 두면
> 직원은 **이름만 고르면** 연결됩니다(주소 입력 생략).

## 자주 막히는 곳

| 증상 | 원인 / 해결 |
|---|---|
| “연결 실패: 매장 PIN이 맞지 않습니다” | Code.gs의 `STORE_PIN`(5001)과 앱에 넣은 PIN이 다름 |
| 연결 테스트가 “응답을 해석하지 못했습니다” | 액세스 권한이 **모든 사용자**가 아님 → 새 배포로 다시 |
| 브라우저에 구글 로그인 화면이 뜸 | 위와 같음. “모든 사용자”로 배포해야 로그인 없이 동작 |
| 시트에 안 쌓임 | 배포 주소가 `/exec`로 끝나는지, 시트 탭 이름이 `전체_통합`인지 확인 |
| 코드를 고쳤는데 반영이 안 됨 | **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** |
| 직원이 실수로 지움 | 삭제는 관리자 PIN(0525)이 있어야만 됩니다. 기본은 직원 모드 |

## 이미 연결해서 쓰고 있는데 코드를 새로 받았을 때 (무선/유선 리베이트)

앱이 `리베이트` 한 칸에서 **`무선리베이트` · `유선리베이트`** 두 칸으로 바뀌었습니다.
이미 시트에 연결해 쓰고 있으면 아래 순서로 **한 번만** 올리면 됩니다.

1. 시트 → **확장 프로그램 → Apps Script** → 코드 전체를 지우고 **새 `Code.gs` 전체**를 붙여넣기
2. **💾 저장**
3. **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (주소는 그대로입니다)
4. 앱을 열거나 “지금 동기화”를 한 번 누르면, 시트 첫 요청 때 **예전 단일 리베이트가
   개통유형에 따라 무선/유선 칸으로 자동으로 옮겨지고 헤더가 새 순서로 다시 그려집니다.**
   (예전 `기타`·`키즈폰`·`인터넷+TV` 값은 그대로 두고, 새 등록부터 6개 유형만 보입니다)

> 옮기기 전에 시트 사본(파일 → 사본 만들기)을 하나 떠 두면 마음이 편합니다.

## 직원 · 기기 추방(차단) — 사장님 전용

관리자 모드(PIN `0525`)에서 **더보기 → 직원 · 기기 관리**를 열면 접속한 기기와 직원 이름이 보입니다.

- **기기 추방**: 그 브라우저·폰은 앱을 열어도 장부가 보이지 않고, 저장된 장부도 그 기기에서 지워집니다.
- **직원 추방**: 그 이름으로 쓰는 기기가 모두 막힙니다.
- 언제든 **차단 해제**로 풀 수 있습니다. 차단된 기기는 `다시 확인` 을 누르면 바로 복구됩니다.
- 차단 목록은 시트의 숨김 탭 `_차단`, 기기 목록은 `_접속기기` 에 남습니다.

> 이 기능은 **`Code.gs` 새 버전 배포**가 꼭 필요합니다(아래 “이미 연결해서 쓰고 있는데…” 순서).

## 시트에서 바로 보기

- `전체_통합` : 모든 직원 기록 + `담당자` 열
- `담당_이름` : 그 직원 기록만 자동으로 모이는 보기 탭 (`FILTER` 수식, 고치지 마세요)
- 월별 구분은 앱의 **기준 월** 필터와 `개통일` 열로 처리합니다.
  시트에서 직접 월별로 보고 싶으면 `피벗 테이블`을 `전체_통합` 기준으로 하나 만들어 두면 편합니다.

## v8.9 — 밴드앱(칠금점 가망고객) 실시간 공유도 같은 스크립트에 들어 있습니다

`Code.gs` 를 이번 버전(v8.9)으로 한 번 올리면, **개통장부**와 **칠금점 가망고객(730·550·3년 밴드 앱)** 이
같은 시트·같은 배포 주소를 함께 씁니다.

- 새로 생기는 것: 숨김 탭 **`_밴드공유`** (밴드앱의 고객 상태·메모·예약·댓글·글) — 지우거나 고치지 마세요.
- 새 요청: `action=band_get`(바뀐 것만 받기) / `action=band_push`(바꾼 칸만 올리기)
- 개통장부 쪽 동작(`list`·`ping`·`upsert`·`delete`·기기 승인·추방)은 **그대로**입니다. 앱도 그대로 쓰시면 됩니다.

> ⚠️ **꼭 지금 쓰는 그 스크립트에서** 붙여넣고, **새 프로젝트를 만들지 마세요.**
> `배포 → 배포 관리 → 지금 쓰는 배포의 연필(✏️) → 버전: 새 버전 → 배포` 로 **버전만** 올리면
> 주소(`…/exec`)가 그대로라서 두 앱 다 수정할 게 없습니다.
> 새 배포를 만들면 주소가 바뀌어 두 앱 모두 주소를 다시 넣어야 합니다.

배포가 끝나면 밴드앱은 **30초 안에 스스로** 실시간 공유를 켭니다(앱 업데이트 필요 없음).
그 전까지는 화면에 아무 오류 없이 혼자 쓰는 모드로 동작합니다.

## v9.0 — 장부를 달(月) 단위로 나눠 주고받습니다 (앱 v79)

공용 장부가 1만 건(약 5.3MB)이 되면서 앱을 열 때마다 전체를 받느라 4~5초 걸렸습니다.
이제 `Code.gs` 가 **달 단위 조회**를 함께 제공하고, 앱(v79)은 그것만 씁니다.

- 새 요청 두 가지 (주소·PIN·기기 승인 규칙은 기존과 같습니다)
  - `?pin=5001&action=list_months` → 달(YYYY-MM)별 **건수·체크섬·마지막 수정시각** (약 4KB)
  - `?pin=5001&action=list_month&month=2026-11` (또는 `months=2026-11,2026-10`) → **그 달 행만** (1개월 약 100KB)
- 기존 `action=list`(전체) · `action=band_get` · `action=band_push` · `upsert` · `delete` · 기기 승인·추방은 **그대로**입니다.
  → 밴드앱(칠금점 가망고객)과 예전 앱 버전은 아무것도 바꾸지 않아도 됩니다.
- 앱이 달 조회를 모르는 서버를 만나면(구버전 배포) 예전처럼 `action=list` 로 스스로 돌아갑니다.
- 배포 방법은 v8.9 와 같습니다: **지금 쓰는 배포의 연필(✏️) → 버전: 새 버전 → 배포** (주소 그대로).
