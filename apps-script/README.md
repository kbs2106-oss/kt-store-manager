# 공용 장부 연결 안내 (사장님용)

개통장부 앱의 기록을 **구글 시트 한 곳에 모으고, 직원 폰과 실시간으로 맞추는** 설정입니다.
**한 번만** 하면 되고, 걸리는 시간은 3~5분입니다.

- 시트: **충주 KT대리점 칠금점 개통장부**
  https://docs.google.com/spreadsheets/d/1DjKKQT9K2ryDKjRL88B31pMhdqgqlzEX39uDbG8F4E4/edit
- 시트 구조: `전체_통합`(모든 기록) + `담당_김태양` `담당_김설화` `담당_이건엽` `담당_권영한`(자동 분류 보기)
- 매장 접속 PIN: **5001** (조회·등록·수정)
- 관리자 PIN: **0525** (삭제·엑셀·백업 — 앱의 관리자 모드)

---

## 1단계 — 시트에 스크립트 붙이기

1. 위 시트를 엽니다. (사장님 계정 `kbs2106@nate.com`으로 로그인된 상태)
2. 위쪽 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 새 창에 코드가 조금 적혀 있으면 **전부 지웁니다** (Ctrl+A → Delete).
4. 이 폴더의 **`Code.gs` 파일 내용 전체**를 복사해 붙여넣습니다.
5. 위쪽 **💾 저장**(또는 Ctrl+S) → 프로젝트 이름은 `개통장부 연동` 정도로.

> 폰에서는 시트 앱 → 우측 상단 ⋮ → "부가기능" 메뉴가 없어 확장 프로그램을 열 수 없습니다.
> **이 1단계만 PC(또는 태블릿 데스크톱 모드)에서** 하시고, 나머지는 폰에서도 됩니다.

## 2단계 — 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 왼쪽 톱니바퀴(유형 선택) → **웹앱**.
3. 아래처럼 설정합니다.
   - 설명: `개통장부 공용 저장소`
   - **실행 대상: 나**
   - **액세스 권한: 모든 사용자** ← 이게 아니면 직원 폰에서 로그인 화면이 떠서 연결이 안 됩니다
4. **배포** → 구글 계정 권한 요청이 나오면
   `권한 검토 → 계정 선택 → 고급 → (안전하지 않음) 이동 → 허용`.
5. 나오는 **웹앱 URL**(`https://script.google.com/macros/s/AKfy…/exec`)을 복사합니다.

## 3단계 — 앱에 주소 넣기 (사장님 폰/PC)

1. 개통장부 앱을 엽니다. (https://kbs2106-oss.github.io/kt-store-manager/)
2. **더보기 → 공용 장부 연동 (Google 시트)**.
3. **연동 주소**에 복사한 `/exec` 주소를 붙여넣고, **매장 PIN** `5001`, **내 이름** `김태양` 선택.
4. **연결 테스트** → “연결 성공! 시트에 N건이 있습니다.” 가 나오면 **저장**.
5. 상단에 `공용 장부 · 방금 동기화` 배지가 뜨면 성공입니다.

## 4단계 — 직원 폰 연결

직원은 같은 앱 주소를 열고 **더보기 → 공용 장부 연동**에서
**연동 주소 + PIN 5001 + 자기 이름**(김설화 / 이건엽 / 권영한)만 넣고 저장하면 됩니다.
이후 서로 등록한 개통이 **각자 폰에 자동으로** 나타납니다.

> 앱 상단의 `index.html` 안 `DEFAULT_SYNC` 에 배포 주소를 넣어 두면
> 직원은 **이름만 고르면** 연결됩니다(주소 입력 생략).

## 자주 막히는 곳

| 증상 | 원인 / 해결 |
|---|---|
| “연결 실패: 매장 PIN이 맞지 않습니다” | Code.gs의 `STORE_PIN`(5001)과 앱에 넣은 PIN이 다름 |
| 연결 테스트가 “응답을 해석하지 못했습니다” | 액세스 권한이 **모든 사용자**가 아님 → 새 배포로 다시 |
| 브라우저에 구글 로그인 화면이 뜸 | 위와 같음. “모든 사용자”로 배포해야 로그인 없이 동작 |
| 시트에 안 쌓임 | 배포 주소가 `/exec`로 끝나는지, 시트 탭 이름이 `전체_통합`인지 확인 |
| 코드를 고쳤는데 반영이 안 됨 | **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** |
| 직원이 실수로 지움 | 삭제는 관리자 PIN(0525)이 있어야만 됩니다. 기본은 직원 모드 |

## 시트에서 바로 보기

- `전체_통합` : 모든 직원 기록 + `담당자` 열
- `담당_이름` : 그 직원 기록만 자동으로 모이는 보기 탭 (`FILTER` 수식, 고치지 마세요)
- 월별 구분은 앱의 **기준 월** 필터와 `개통일` 열로 처리합니다.
  시트에서 직접 월별로 보고 싶으면 `피벗 테이블`을 `전체_통합` 기준으로 하나 만들어 두면 편합니다.
